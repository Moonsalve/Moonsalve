# Hi, I'm Juan 👋

### Systems & Computing Engineer · Software Engineer — backend, cloud & applied AI

📍 Colombia (GMT−5) &nbsp;·&nbsp; 🌐 **[jmonsalve.dev](https://jmonsalve.dev)** (ES / EN)

I'm a Systems & Computing Engineer from Colombia. Most of my work is on the backend —
typed APIs, relational data models, and the deployment that carries them — and on applied
AI, where what interests me is less the model itself than deciding whether it belongs on the
critical path at all.

I tend to operate what I build, not just ship it. That has meant running a league-management
platform on a self-hosted server for a football league that uses it every day, and building a
Spanish voice assistant that works with no internet connection at all. Day to day I work in
**Python**, **TypeScript** and **Java**, with **Node/Express** and **FastAPI** on the server,
**PostgreSQL** underneath, and **Docker** for anything that has to run somewhere other than my
laptop. I came up through technical support and operations, which is why I care about logs,
backups you have actually restored, and software that someone else can install without me.

- 🔭 **Currently:** operating **EM Torneos** in production and looking for a backend or applied-AI role.
- 🧠 **Building:** **Apollo**, a local-first Spanish voice assistant.
- 🌱 **Next:** commercial LLM APIs in server-side workflows — inbound webhooks, structured extraction, and the cost and latency accounting that comes with them.
- 📫 **Reach me:** [JuanMonsalve.23@hotmail.com](mailto:JuanMonsalve.23@hotmail.com)
